# RASUN

依据《雷达 RASUN 需求文档》实现的全链上算力挖矿开发版：DApp、只读运营后台、链上索引 API、代币/邀请/日结算合约。

**交付范围为本地和 BSC 测试网。不是已经审计、可直接投入真实资金的主网产品。**

## 开发环境与一键运行

Node.js 22 LTS（也验证于当前云环境 Node 24）、pnpm **9.15.9**。Windows 使用 PowerShell 或 CMD，先安装 Node.js 与 Git，再安装指定 pnpm。每个云任务已有隔离工作区，直接使用现有 checkout，不需要另建 worktree。

```sh
npm install -g pnpm@9.15.9
```

旧版 uni-app 自动化依赖带有可选 Chromium 下载；本项目浏览器验证使用独立 Playwright 与本机 Chromium。安装时跳过该旧浏览器：

```sh
# macOS / Linux
PUPPETEER_SKIP_DOWNLOAD=1 pnpm install --frozen-lockfile
```

```powershell
# Windows PowerShell
$env:PUPPETEER_SKIP_DOWNLOAD="1"
pnpm install --frozen-lockfile
```

```bat
:: Windows CMD
set PUPPETEER_SKIP_DOWNLOAD=1
pnpm install --frozen-lockfile
```

启动完整本地开发环境：

```sh
pnpm dev:local
```

此命令为本次启动分配四个空闲端口，在 `.local/runs/<运行编号>/` 创建独立 SQLite 索引、部署文件和日志，编译 API、启动新的本地 Hardhat 链、部署合约、准备持仓与邀请样例、结算一个完整日，再启动 API、DApp 和后台。

- DApp：默认本机端口 **5173**，占用时自动选择下一个空闲端口。
- 后台：默认本机端口 **5174**，占用或与 DApp 冲突时自动选择其他空闲端口，只读，不托管私钥。
- API：默认本机端口 **3000**，占用时自动顺延，前缀 `/api`。
- 本地链：默认本机端口 **8545**，占用时自动顺延，chain ID **31337**。
- 日志路径和四个服务的实际地址会在终端输出，并记录于 `.local/dev-urls.json`；按 Ctrl+C 只停止该命令创建的服务。每次启动的记录还保留在 `.local/runs/<运行编号>/urls.json`。
- 启动成功后会输出前台、后台的实际访问地址，并写入 `.local/dev-urls.json`；请打开这些地址，避免继续访问旧端口上的旧页面。独立运行 `pnpm dev:dapp` / `pnpm dev:admin` 也会自动顺延端口。四个服务都会避开占用端口，不会停止、重置或复用旧服务；前端代理、API、部署与测试自动使用本次分配的地址。

本地链使用公开测试账户。不要将这些账户用于任何真实网络或充值。可以把 Hardhat 日志中账户 #7 导入开发钱包检查两类待领收益；它的地址也由 `/api/config` 的 `demoWallet` 提供。钱包网络必须与本地链一致。若本地链改用其他端口，请将钱包内 chain ID 31337 的 RPC 地址更新为终端输出的 `Local RPC`；同 chain ID 的旧链也会被身份校验拦截，并提示正确 RPC，不会向旧链发送交易。浏览器自动化通过本地解锁账户发送真实本地链交易，不伪造交易成功。

运行中的进程不随云快照保存。新任务需重新运行启动命令。SQLite 是可重建索引，不是资产账本。重启本地开发栈会创建新的临时链，不会保留本地测试资产；已有链上主网/测试网数据不会被本地命令修改。

## 已实现

### 合约

- 初始两百万枚，矿工与流动性分配地址各一百万；累计铸造上限一亿，销毁不恢复额度。
- 每月按 30 日计，第一月十万；2–6 月增长 10%，7–42 月增长 5%，43–78 月增长 3%，79 月起增长 1%；触及一亿时截断最终一期。按该阶段切换约定，第 86 个月发行结束。
- 买入基础税 3%，卖出基础税 5%；相对 UTC+8 当日开盘价跌幅达到 10/20/30% 时附加 5/10/15% 卖出税；附加税一半销毁，一半进入调控地址。钱包间转账免交易税。
- UTC+8 日终历史余额检查点、余额低于一枚排除、并列竞争排名、直推分段权重及定点立方根。
- 一次邀请绑定，拒绝自邀与循环。新绑定向上检查最多 256 层，超过预算拒绝，不做无界递归。
- 任何人可分批完成日结算；历史持仓与关系不受结算期间转账影响。持币、推广分别领取、累计可领、防重领；每次最多处理 365 日，零收益历史页也可以前进。
- 确定顺序累计比例差分分配，避免有效收益池留下舍入尾差；无有效权重的池记录为未分配储备，不转给其他类别。

### 前端

紫粉渐变、浅粉卡片、雷达轨道与立体品牌视觉，参考 PDF 宣传图。移动端与桌面布局；总览、排名、邀请绑定、独立收益领取、收益记录；七种语言；钱包账户和网络变化处理、拒签反馈、确认后刷新、服务不可用状态、原生键盘可访问按钮。

### API / 后台

NestJS + Prisma JavaScript 引擎 + libSQL SQLite 适配器，无需下载 Prisma Rust 引擎。后端只查询与索引，不决定收益、不持有用户密钥。确认区块索引、交易日志幂等、区块哈希校验、重组回滚重放。

主要接口：

| 路径                                                   | 返回                                             |
| ------------------------------------------------------ | ------------------------------------------------ |
| `/api/health`                                          | API、链与索引状态                                |
| `/api/config`                                          | 公共链配置、地址、ABI、测试模式标记              |
| `/api/overview`                                        | 发行、销毁、价格有效性、税率、日结算进度         |
| `/api/ranking?page=1&limit=10`                         | 当前余额升序排名，余额不少于一枚                 |
| `/api/wallet/0x…`                                      | 余额、最近已结算算力、邀请、分类型待领及历史游标 |
| `/api/market?wallet=0x…`                               | 测试池储备、tUSDT、授权、Gas、水龙头冷却与轮次 |
| `/api/events?page=1&limit=10&wallet=0x…&event=Claimed` | 分页已确认事件，可按钱包/事件过滤                |

金额均为最小单位十进制字符串。排名区域仅描述当前分布，不承诺收益率；当前排名不替代历史收益快照。

## 验证

```sh
pnpm verify
```

运行全部合约测试、钱包生命周期测试、API 与两个前端生产构建。

完整集成验证需要 Chromium。当前云环境为 `/usr/bin/chromium`；其他机器设置 `CHROMIUM_PATH` 为浏览器可执行文件路径。

```sh
pnpm check:local
```

该命令启动自己管理的全新本地栈，运行 API、真实链重组与浏览器测试后停止服务。开始前请停止 `dev:local`；四个端口均自动避让；浏览器测试自动读取本次启动的实际地址。浏览器交易测试保存并恢复本地链快照，截图在 `test-results/`。不会连接 BSC 或发送真实资金。

也可分别运行：

```sh
pnpm contract:test
pnpm test:wallet
pnpm test:api     # 需要已启动且有初始样例的本地栈
pnpm test:ui      # 需要本地栈及 Chromium
pnpm local:settle # 使用当前运行记录中的 RPC 和部署文件，进入新一天后分批结算
```

## 配置和 BSC 测试网

API 可将 `apps/api/.env.example` 复制为 `apps/api/.env`，设置 RPC、部署文件、索引确认数和本地数据库。`PUBLIC_RPC_URL` 只允许填写无凭据的公共钱包 RPC；不要把带密钥的私有 RPC 暴露给前端。相对 SQLite 文件路径以 `apps/api` 为基准。

要使用真实 **BSC 测试网（chain ID 97，Gas 为 tBNB）**，请使用下面的测试网命令。`dev:local` 会创建 Hardhat 本地链，不能代替公共测试网部署。

1. 在本机执行 `Copy-Item .env.example .env`（PowerShell），用编辑器在 `.env` 填写仅用于测试的 `DEPLOYER_PRIVATE_KEY`。不要把私钥、助记词或 `.env` 发到聊天或提交 Git。部署钱包需要先取得至少 0.02 tBNB，实际部署费用随网络变化；使用 BNB Chain 官方测试网水龙头取得测试资金。其他测试钱包也需要 tBNB 支付交易 Gas。
2. 保留默认公共 RPC；如更换，必须指向 chain 97。`MINER_ADDRESS` 与 `LIQUIDITY_ADDRESS` 留空，测试部署自动用部署钱包注入测试池；其他金库地址可留空或指定测试地址。
3. 依次运行：

```sh
pnpm deploy:testnet
pnpm dev:testnet
```

部署会确认每笔链上交易，生成 `deployments/testnet.json`（全部七个合约地址与 ABI）。已有部署文件会拒绝覆盖，避免误部署。`dev:testnet` 校验 chain 97 与合约代码，启动只读 API、DApp 和后台，**不会启动本地链、重部署或重置测试网资产**。打开终端实际输出的新地址，钱包连接后切换到 BSC 测试网；不要继续使用旧 Hardhat 页面。数据索引按链和代币地址持久化，并等待 12 个确认。

如果 Windows 系统代理可联网、Node 直连 RPC 超时，在根 `.env` 增加 `HTTPS_PROXY=http://127.0.0.1:7890`、`HTTP_PROXY=http://127.0.0.1:7890`（端口改为实际 HTTP 代理端口）。启动脚本、只读 API 和 keeper 会使用同一 HTTP CONNECT 代理；localhost/127.0.0.1/::1 始终直连，其他直连域名可用 `NO_PROXY` 指定。保持代理软件运行，不要关闭 TLS 证书校验。已部署成功后只运行 `dev:testnet`，无需重新部署。

测试闭环：

- 用一个独立测试钱包连接前台，点击测试水龙头，实际链上领取 **100 RASUN + 1000 tUSDT**，每地址真实 24 小时一次。初始分配和金库钱包不参与挖矿，请不要用部署钱包测试持币收益。
- 在测试池输入金额，买入或卖出。界面进行精确额度授权、检查实际到账最小值，并在确认后刷新余额。tUSDT 是无价值测试资产，**不是 USDT；测试池不是 PancakeSwap**。RASUN 买卖税和销毁真实执行，可在 BscScan 查看代币与交易。
- 默认 `RASUN_EPOCH_SECONDS=300`：每 **5 分钟**一轮测试结算，发行表中的“一日”对应一个测试轮次，因此发行也被加速。界面明确显示测试时钟。若要按原需求 UTC+8 每日结算，部署前改为 `86400`；部署后时钟不可更改。
- 领取后持有 RASUN，等到下一轮。任何人可用前台按钮启动结算、分批处理（每批最多 128 操作）；看到可领取金额大于 0 后领取，余额会真实增加。无收益时领取按钮禁用，历史游标处理另有按钮且需要 Gas。
- 也可在另一个本机终端运行 `pnpm keeper:testnet` 自动按轮次分批结算。它用本机 `.env` 的测试私钥支付 Gas；API 不接触私钥。结算有多个阶段，可能需要多笔交易；暂停后可继续。没有新轮次时不发送交易。
- 推广收益需另一测试钱包绑定邀请并持币；只连一个钱包不会凭空产生推广收益。

**公共 BSC 部署尚未执行**：当前环境没有可用的已资助部署密钥。仓库代码、本地实链测试与公共部署是不同的验证层级；只有完成上面的部署、获得 chain 97 交易回执后，才能确认已上线测试网。无需向我发送私钥；可以提供公开合约地址与交易哈希供核验。

`pnpm check:testnet` 是本机隔离的 Hardhat 集成验证，明确标注 fixture，可时间快进；它不是公共 BSC 部署证据。测试网启动不会自动回退到该 fixture。

## 必须了解的限制

1. **测试价格源不是生产预言机。** 开发版 `TestPriceOracle` 由 owner 设置，明确标记为测试；真实交易前必须接入可验证的历史价格与抗操纵适配器，审查交易对、报价资产、流动性与观察窗口。不能把当天首次访问的价格冒充 UTC+8 零点价格。缺少有效价格时池卖出拒绝，普通转账和领取仍可用。
2. **全链上排名有成本。** 本版本朴素排名 O(N²)，100 个地址的完整日结算实测约 **1.49 亿 Gas、42 笔交易**（每批 256 操作）。分批解决单笔上限，不解决全网扩展性。生产化还需要更高效排名结构、粉尘地址攻击治理及长期存储预算。
3. **不构造真实 LP。** 五十万 USDT + 一百万 RASUN 是需求中的池初始资金要求，部署不会凭空提供 USDT，也没有进行真实 DEX 路由和加池实测。本地基础开发版只测税费分支；新增 BSC 测试沙盒用无价值 tUSDT 注入测试池，不能代替真实 USDT/PancakeSwap 集成。
4. 本版本累计铸造上限与月度排程优先于文档中互相矛盾的“第四阶段十个月”。邀请仅计算直属下级；文档例子 A 约 43546.415888，C 为 90010。
5. 管理台为公开数据的只读视图；没有管理员资产操作或密码后台。若未来加入写操作，必须单独设计鉴权、权限与审计。
6. 主网部署前仍需独立合约审计、生产价格源、规模优化、DEX 集成测试与金库多签等工作。本地验证通过不等于主网上线许可。

设计和实施记录见 `docs/superpowers/`。不要提交 `.env`、数据库、私钥或运行日志。

本地运行会保留多套独立数据。手动 `local:settle` 默认使用最近一次仍有运行记录的环境；若没有当前记录，不会回退连接旧的 8545。针对另一个运行实例调试时，请显式设置 `RASUN_LOCAL_RPC_URL` 和 `DEPLOYMENT_FILE`（从该实例的 urls.json 读取）。不要向正在运行的一键环境单独重新部署合约；运行 `pnpm dev:local` 创建一套新的、一致的环境即可。
