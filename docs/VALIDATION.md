## 独立审查及修复

独立审查发现的三项重要问题均已修复：

1. 索引内部重组竞态：改为按 blockHash 读取日志，检查 parentHash 连续性和提交前块哈希。两项确定性竞态先失败后通过，另有真实 Hardhat 链重组回放测试。
2. 钱包异步交易窗口：在最终 EIP-1193 eth_sendTransaction 边界核对会话、账户、当前链，固定 chainId。钱包单测与浏览器 Gas 估算期间切链回归通过。
3. 本地启动混用测试网配置：本地模式显式固定 RPC、部署文件、数据库、端口及确认数，并核对部署标识；错误远端环境变量下完整验收通过。

同时处理了首次连接事件顺序、管理端旧查询覆盖及测试网结算默认部署文件问题。无遗留审查小项。

数据库初始化使用版本化幂等 SQL 与显式关闭连接；Prisma JavaScript 客户端负责运行时查询。避免了实验性 Prisma schema push 完成后句柄不退出的问题，不关闭 TLS、签名或校验和验证。

## 实测范围

没有执行公共 BSC 测试网或主网部署、真实 DEX 流动池操作、真实 USDT 注资或生产预言机验证。本地测试 oracle 和 O(N²) 排名不应作为可投入真实资金的生产能力。生产化前置条件见 README。
